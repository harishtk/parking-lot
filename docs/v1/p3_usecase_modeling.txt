1. Park Vehicle

Input
  RegistrationNumber
  VehicleType

Preconditions
  Vehicle is not already parked
  Parking lot has available capacity

Flow
  ParkingService -> SpotSelectionPolicy -> Select spot -> ParkingLot.allocate() - Create Allocation ->
      Create Ticket -> Store Active

State Changes
  Spot allocations updated
  Active ticket added
  Vehicle index added

Failures
  Vehicle already parked
  No suitable spot available

Output
  TicketId
  Allocated SpotId

---
2. Unpark Vehicle

Input 
  TicketId

Preconditions
  Ticket exists
  Ticket is ACTIVE

Flow
  Find active ticket -> Determine allocation -> Calculate fee -> Release allocation -> Close ticket -> Persist historical ticket

State Changse
  Allocation removed
  Ticket removed from active tickets
  Ticket saved to repository
  Vehicle index removed

Failures
  Unknown ticket
  Already closed ticket

Output
  Fee
  Duration
  Spot released
